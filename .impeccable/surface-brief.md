# Alice desktop worktree cleaner

Scope: native Rune onboarding, multi-repository scan report, evidence expansion, cleanup confirmation, and result screens.
Mode: Operate. The user repeatedly reclaims disk space from agent-created Git worktrees without losing active work.
Proof: real Git status, merge containment, upstream counts, disk size, and last-commit evidence. Demo scenes are labeled DEMO DATA.
Constraints: confirmation for every batch; only clean, merged, contained linked worktrees are selectable; dirty, unpushed, locked, primary, detached, and uncertain work stays protected; Kimi is optional and advisory.

## Direction contract

THESIS: A small robot maid does the dirty job agents leave behind. The complete user-supplied `idea/` prototype replaces the previous visual direction; its three-pile report and hand-written verdicts are the authority.

OWN-WORLD: Pure white paper, warm gray wash, thin neutral rules, black Inter, JetBrains Mono for branches and paths, Kalam for Alice's notes. Red means sweep, orange means ask, blue means keep. Local Magic Patterns illustrations show Alice greeting, sweeping, and having tea.

STORY: The user connects their existing Kimi Code subscription, chooses a repository or folder, reviews sweep/ask/keep piles with evidence, confirms a safe batch, and sees real reclaimed space. No fake bin, undo, schedule, or unsupported provider actions.

FIRST VIEWPORT: At 1200×780, a 48-point unified bar leads. The report has a 218-point repository rail, a selected-space hero with disk bar and sweeping illustration, then stacked verdict groups. A fixed footer holds the review action; confirmation uses a protected-focus dialog.

FORM: User-pinned Magic Patterns prototype in `idea/`; supersedes the earlier roll (seed:ef2c40eb02d6f736). Code-led native implementation in Rune.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
